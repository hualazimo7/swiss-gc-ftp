## SwissFTP（PC 端传文件到 SD 卡）

不用拔卡，把 PC 上的 ISO / DOL / 封面 / 补丁直接写进 GameCube 的 SD 卡。
**不需要改固件、不需要刷 `IPL.dol`**，用的是现行版本里已有的 httpd 端点。

### 为什么界面叫 FTP、协议却不是 FTP

Swiss 固件里只有 FTP **客户端**（`devices/ftp/`，用来浏览 PC 上 `ftp_server.py`
开出来的 `<PC 共享目录>` 游戏库），**没有对外提供 FTP 服务**。PC 想写 SD 卡，
唯一现成通路是 httpd(80) 的 FatFs 端点。因此：

| 层 | 实现 |
|---|---|
| 双栏 GUI | FTP 客户端式操作（本地 ⇄ SD 卡、队列、进度、覆盖确认） |
| 传输后端 | Swiss httpd：`/ls` `/upload` `/get` `/rm` `/rename` `/state` |
| FTP 网关（可选） | 在 PC 本机 `127.0.0.1:2121` 起标准 FTP 服务，把 FTP 命令翻译成上述端点，供 FileZilla / 资源管理器 / curl 使用 |

### 文件

| 文件 | 作用 |
|---|---|
| **`dist/SwissFTP.exe`** | **成品：单文件 Windows 程序，免装 Python，双击即用** |
| `tools/启动 SwissFTP.bat` | 一键启动（优先用上面的 EXE，没有才回退源码） |
| `tools/启动 FTP 网关.bat` | 只起 FTP 服务，不弹界面（同样优先 EXE） |
| `tools/swiss_ftp.py` | GUI + CLI 主程序（源码入口） |
| `tools/swiss_client.py` | 协议层，纯标准库，可单独 import |
| `tools/swiss_ftp_gateway.py` | 标准 FTP 服务端（被动模式） |
| `tools/mock_swiss.py` | 照抄固件解析逻辑的本地模拟服务，用于无实机自检 |
| `tools/build_exe.py` / `tools/打包 EXE.bat` | 重新打包 EXE（PyInstaller 6 + Python 3.14） |
| `tools/make_icon.py` / `tools/assets/swissftp.ico` | 生成程序图标（蓝底 SD 卡 + 上传箭头） |

配置保存在 `~/.swissftp.json`（IP、端口、卷、主题、最近目录），EXE 与源码共用同一份。

### EXE 版本（`dist/SwissFTP.exe`）

- **单文件 13.11 MiB**（64 位 Windows 10/11），PyInstaller onefile + GUI 子系统：
  双击只弹程序窗口，**没有控制台黑窗**；自带 Python 3.14 运行时、tkinter/Tcl-Tk，
  目标电脑**不需要装 Python**，也不用带任何其他文件。
- 图标与文件属性（产品名 / 描述 / 版本）已内嵌；已验证在**中文路径**、**PATH 里没有 Python**
  的环境下都能启动。
- 带命令行参数（`--cli` / `--selftest` / `--version` 等）时自动挂到父控制台输出；
  从快捷方式等无控制台环境启动则新建一个控制台。任何模式都可加 `--log 文件.log`
  把输出同时写文件，便于无人值守自检或排错。
- 首次启动会比源码版慢 1–2 秒（onefile 需要把运行时解压到临时目录），之后是正常速度。
- 重新生成：双击 `tools/打包 EXE.bat`，或
  `py -3 tools/build_exe.py`；需要 `pyinstaller>=6` 与 `pillow`。
  产物固定覆盖 `dist/SwissFTP.exe`。改了 `swiss_ftp.py` / `swiss_client.py` /
  `swiss_ftp_gateway.py` 之后必须重新打包，EXE 里是打包那一刻的快照。
- 少数杀毒软件对 PyInstaller 单文件有启发式误报，若被拦截请加入白名单，或从源码
  `tools/启动 SwissFTP.bat` 回退运行。

### 快速开始

```text
# 1. 图形界面（推荐）
双击 dist\SwissFTP.exe            # 或 tools\启动 SwissFTP.bat
#    顶部填 Swiss 的 IP（实机 192.168.1.2）→「连接」→ 左栏选文件 →「上传选中」

# 2. 让 FileZilla / 资源管理器直接连 SD 卡
双击 tools\启动 FTP 网关.bat
#    ftp://127.0.0.1:2121  用户名密码任意

# 3. 命令行（在 dist 目录打开 cmd；源码方式把 SwissFTP.exe 换成
#            py -3 ..\tools\swiss_ftp.py）
SwissFTP.exe --cli --host 192.168.1.2 --ls sdb:/games/
SwissFTP.exe --cli --put D:/game.iso sdb:/games/game.iso
SwissFTP.exe --cli --get sdb:/swiss/settings/global.ini out.ini
SwissFTP.exe --cli --gateway --host 192.168.1.2 --gateway-port 2121

# 4. 自检（无需实机，17 项）
SwissFTP.exe --selftest --log selftest.log
#    只测协议：--protocol-selftest；界面连模拟服务：--mock；查版本：--version
```

### 功能

| 功能 | 说明 |
|---|---|
| 双栏浏览 | 本地磁盘 / SD 卡，中文文件名、大小、类型、修改时间，双击进目录 |
| 批量上传 | 多选、选文件夹递归、覆盖/跳过/全部覆盖、串行队列、进度与速率 |
| 下载 / 改名 / 删除 | `GET /get` `/rename` `/rm`，带确认；下载先写 `.part` 再原子替换 |
| 卷自适应 | 按固件 `pick_upload_root` 顺序探测 `sdb:/ → sda:/ → sdc:/` |
| FTP 网关 | PASV/EPSV、LIST/NLST/MLSD、RETR/STOR、SIZE、DELE、RNFR/RNTO、UTF-8 |
| 主题 | 浅色 / 低饱和深色磨砂，一键切换并记忆 |

### 限制（都来自固件侧）

- **前提**：Swiss 停在主界面、网络已初始化、当前设备是 SD 卡。切到 SMB/FTP/FSP 后
  SD 卷卸载，`/upload` `/get` `/rename` 会返回 `FR_NOT_ENABLED(12)`；跑游戏时 httpd 不响应。
- **没有 mkdir 端点**：上传子目录前该目录必须已存在；网关的 `MKD` 会回 550。
- **覆盖式写入、无续传**：`/upload` 用 `FA_CREATE_ALWAYS`，`/upload` 必须先给
  `Content-Length`，所以 FTP `STOR` 会先把整文件缓冲到本机临时文件再转发（占等量磁盘）。
- **单线程**：httpd 一次只 accept 一个连接；工具内部用锁和单 worker 队列串行化。
- FAT32 单文件 < 4 GiB；空文件拒绝上传；请求头必须 < 1024 字节（固件 `temp[1026]`）。
- 路径里不能含 `..`（固件明确拒绝）。

### 自检覆盖

`--selftest` 用 `mock_swiss.py` 起本地 httpd，依次验证：连通、卷探测、列目录、
中文/空格文件名的上传与回读 SHA-256、上传校验、进度回调、改名、删除、错误传播、
标准 `ftplib` 走网关的 LOGIN/NLST/CWD/LIST/RETR/STOR/SIZE/RENAME/DELE，
以及 GUI 的连接、网关按钮、上传队列、下载队列、删除。实测 **17/17 PASS**。

**EXE 产物独立复验**（不是只测源码）：`dist/SwissFTP.exe --selftest` 同样 **17/17 PASS**；
`--protocol-selftest` 12/12；`--cli --ls` 正常列目录；EXE 常驻 FTP 网关后，
标准 `ftplib` 的 NLST/CWD/STOR（中文名）/RETR（SHA-256 一致）/SIZE/DELE 全过；
`--version`、`--log`、中文路径、PATH 中无 Python、GUI 子系统无黑窗均逐项确认。

### 实机验证（2026-11-08，GameCube 真机）

主机回到 Swiss 主界面、当前设备「SD 卡 - 插槽 B」后逐项实测：

| 项目 | 结果 |
|---|---|
| `SwissFTP.exe --cli --ls sdb:/` / `--state` | 列出根目录 18 项、`/state` 中文设备名正常 |
| 上传中文名到子目录 / 回读 / 改名 / 删除 | 51,228 B，SHA-256 一致，0.23 s，测试文件已清理 |
| `SwissFTP.exe --cli --get ...global.ini` | 下载 2002 B，内容完整 |
| EXE 常驻 FTP 网关 + `ftplib` | NLST/CWD/STOR（中文名）/RETR（SHA-256 一致）/SIZE/DELE 全过 |
| EXE GUI 连接 | 状态「已连接 192.168.1.2」，右栏显示 SD 卡 18 项，无报错 |
| **冷启动验证（19:17 断电重启）** | 首页含「Read a file」、`/get` 读回 `global.ini` 2,002 B、`/state` 正常、`sdb:/IPL.dol` = 1,027,424 B、EXE `--ls/--state` 正常、默认背景亮度 70.5（无 `backdrop.tpl`） |

**关键前提：固件必须含 `/get` 端点**。当时 SD 上的 `IPL.dol` 是 14:17 的旧打包版，
没有 `/get`（首页也没有「Read a file」），所以下载 / FTP 的 RETR / 读 `global.ini`
全部失败。已把含 `/get` 的版本重新打包并轮换到 `sdb:/IPL.dol`
（1,027,424 B，回读 SHA-256 一致；旧版备份在 `tmp/` 和 `sdb:/IPL_old.dol`）。
**改过固件源码后必须重新打包，否则冷启动又会退回旧功能。**
